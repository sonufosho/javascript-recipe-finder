# JavaScript Recipe Finder

A web application that helps you discover recipes from around the world. Simply search for any meal or ingredient, and get detailed recipes with instructions and ingredients list.

## 🌐 Live Demo

👉 [JavaScript Recipe Finder](https://sonufosho.github.io/javascript-recipe-finder/)

## 🌟 Features

- Search recipes by name or ingredients
- View detailed recipe instructions
- See ingredients with measurements
- Clean and responsive user interface
- Real-time search results

## 💡 Usage

1. Enter a meal name or ingredient in the search box
2. Click the search button or press Enter
3. Browse through the search results
4. Click on any recipe to view detailed instructions and ingredients

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [TheMealDB API](https://www.themealdb.com/api.php) for recipe data
- Remix Icons
- Inter Font Family

## 🏃‍♂️ How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/sonufosho/javascript-recipe-finder.git
   ```
2. Navigate to the project directory
3. Open `index.html` in your web browser

## 📝 API Reference

This project uses the free version of TheMealDB API:
- Base URL: `https://www.themealdb.com/api/json/v1/1/`
- Search by name: `search.php?s=`
- Lookup by ID: `lookup.php?i=`
